# 物理引擎模拟器 | Physics Engine Simulator

⚡ 交互式物理力学可视化工具

## 🎯 功能特性

### 支持的物理力

- **🔄 弹簧力** - 可调劲度系数和阻尼比
- **🌍 重力** - 可调重力加速度
- **💨 风力** - 恒定风力或周期性风力
- **🧲 磁力** - 距离平方反比律
- **⚡ 电场力** - 距离平方反比律
- **🛑 摩擦力** - 静摩擦和动摩擦
- **💨 空气阻力** - 速度平方阻力

### 可视化

- **实时动画** - 小球运动轨迹动画
- **位置曲线** - x(t) 时间曲线
- **速度曲线** - v(t) 时间曲线
- **加速度曲线** - a(t) 时间曲线

### 交互控制

- 120fps 高精度物理模拟
- 所有参数实时可调
- 多种物理力组合
- 一键重置

## 📝 物理模型

### 1. 弹簧力 (Hooke's Law)
```
F = -kx - cv
```
- k: 劲度系数
- c: 阻尼系数 = 2ζω₀m
- ζ: 阻尼比
- ω₀: 固有频率 = √(k/m)

### 2. 重力
```
F = mg
```

### 3. 风力
- 恒定风力: F = F₀
- 周期性风力: F = F₀ sin(2πt/T)

### 4. 磁力/电场力 (平方反比律)
```
F = -k/r²
```

### 5. 摩擦力
- 静摩擦: F = -μₛ sgn(v), |v| < v_threshold
- 动摩擦: F = -μₖ sgn(v)

### 6. 空气阻力
```
F = -Cv²
```

## 🎮 使用示例

### 示例 1: 标准弹簧振动
- 启用: 弹簧力
- 劲度系数 k = 60
- 阻尼比 ζ = 0.74
- 初始位置 x₀ = -150

- 启用: 弹簧力 + 重力
- 观察物体在重力作用下如何被弹簧缓冲

### 示例 3: 磁力吸引
- 启用: 弹簧力 + 磁力
- 磁源位置设在 +50
- 观察物体如何被磁力吸引

### 示例 4: 周期性风力
- 启用: 弹簧力 + 周期性风力
- 观察受迫振动现象
